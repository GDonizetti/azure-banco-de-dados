# azure-banco-de-dados
Desafio prático da DIO: criação e configuração de um banco de dados SQL no Microsoft Azure. Este repositório contém o passo a passo da implantação, capturas de tela e anotações técnicas para consulta e aprendizado.


# 📘 Desafio Prático: Criação de Banco de Dados SQL no Microsoft Azure

Este repositório foi desenvolvido como parte do desafio da plataforma DIO, cujo objetivo foi configurar uma instância de banco de dados SQL no Microsoft Azure e documentar a experiência de forma técnica e acessível.

---

## 🎯 Objetivo do Desafio

- Aplicar os conhecimentos adquiridos sobre serviços gerenciados de banco de dados no Azure.
- Criar um banco de dados SQL funcional e acessível.
- Documentar o processo técnico com prints e explicações claras.

---

## 🧠 Observações

- A camada de preço escolhida foi "Uso Geral - Gen5, 1 vCore", adequada para testes e desenvolvimento.
- O banco foi provisionado sem ponto de restauração inicial.
- Utilizei as ferramentas nativas do Azure para conexão e gerenciamento.
